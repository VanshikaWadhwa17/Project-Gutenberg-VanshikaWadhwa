# Project Gutenberg Search Engine (Assignment 1)

A mini search engine for Project Gutenberg books with **indexing**, **three retrieval models** (structured metadata, TF-IDF, BM25), **evaluation**, and a **web interface**.

## What to add locally (not in Git)

These are in `.gitignore` because they are large or downloaded. Add them yourself after cloning:

| What | Where to get it | Where to put it |
|------|-----------------|-----------------|
| **Book texts** (`.txt` files) | [Gutenberg dataset](https://drive.google.com/drive/folders/18thecW1KcxLr5BbpKCTrZrJec71VYx_L) | `data/books/` or `data/books/books/` |
| **metadata.csv** | Same Drive folder | Project root or `data/metadata.csv` |
| **Index files** (`.pkl`) | Generated by `python indexer.py` | `index/` (created automatically) |
| **Query TSV results** | Generated by `python run_queries.py` | `queries/` (created automatically) |

Without the books and metadata, only **structured search** (metadata) works; **TF-IDF** and **BM25** need the index built from the book files.

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Download NLTK stopwords

```bash
python -c "import nltk; nltk.download('stopwords')"
```

### 3. Dataset

- Download the Gutenberg dataset from:  
  https://drive.google.com/drive/folders/18thecW1KcxLr5BbpKCTrZrJec71VYx_L
- Place all `.txt` books in **`data/books/`** (files named by book ID, e.g. `1.txt`, `11.txt`).
- Place **`metadata.csv`** in **`data/`** (or keep it in the project root).

## Usage

### Build the index (after placing books and metadata)

From the project root:

```bash
python indexer.py
```

This creates `index/inverted_index.pkl`, TF-IDF vectors, doc lengths, etc.

### Run the 6 assignment queries and generate TSV files

```bash
python run_queries.py
```

Produces 18 TSV files in `queries/`:  
`1_structured.tsv`, `1_tfidf.tsv`, `1_bm25.tsv`, … through `6_bm25.tsv`.  
Columns: `rank`, `book_id`, `score`, `preview`, `line_number`.

### Start the web app

```bash
python app/app.py
```

Open http://127.0.0.1:5000 — search and compare results across the three models.

## Retrieval models

1. **Structured search** — Match query against metadata (title, author, bookshelf).
2. **Vector space (TF-IDF)** — Cosine similarity between query and document TF-IDF vectors.
3. **BM25** — BM25 scoring with k1=1.5, b=0.75.
